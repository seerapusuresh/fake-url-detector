How it works

The detector checks common URL patterns that may indicate a suspicious website.

HTTPS Checks whether the URL uses secure HTTPS.
IP Address Checks if an IP is used instead of a domain.
@ Symbol Detects symbols that can hide the destination.
Keywords Looks for suspicious words such as login or verify.
Shorteners Detects common URL shortening services.
URL Structure Checks unusually long URLs and excessive subdomains.

This tool uses simple rule-based checks and cannot guarantee that a website is safe.
